Dark mode

Turn light websites dark. Photos and videos are not inverted.

ShortcutSwitch dark mode on or off on any page. To use another key, add map <key> toggleDarkMode in Keyboard.
Alt+D

Common sites with their own dark themes are pre-filled. Enable dark mode in each site’s settings. Edit this list freely: one site per line, including its subdomains.

Excluded sites

Let a website handle some or all keyboard shortcuts itself.

URL patternKeys to pass throughRemove rule

Blank keys disable all Brovim page bindings for that site.

How exclusion rules work

Patterns are URL regular expressions. * matches any number of characters. For example, https?://web.whatsapp.com/* matches WhatsApp Web.

Leave keys blank to disable all page bindings, or enter keys such as j k to pass only those keys to the site. The browser shortcut Alt+Q stays available.

Search engines

Use a keyword in the Vomnibar to search a specific website.

For example, type yt keyboard shortcuts to search YouTube.

Search shortcut format

Use keyword: URL description. Brovim replaces %s with your search terms.

ddg: https://duckduckgo.com/?q=%s DuckDuckGo
